# Ficha de Personaje/Mascota — "Chispa" / "闪闪 Shǎn Shǎn"

Mascota fija para dar consistencia visual entre TODOS los episodios, ambos mercados.

## Concepto
Una pequeña esfera de energía/estrella curiosa con ojos grandes y expresivos, que hace de guía/narrador visual en cada video. Funciona igual en español ("Chispa") y en chino ("闪闪 Shǎn Shǎn", que significa "brillante/destellante").

## Diseño (usar SIEMPRE en los prompts de imagen para mantener consistencia)

**Prompt base de personaje (inglés, pegar en cada prompt de imagen donde aparezca la mascota):**
```
a small round glowing star-shaped mascot character named Chispa, big sparkling round eyes, tiny stubby arms and legs, soft yellow-to-orange gradient glow, cute simple smile, Pixar-style 3D render, consistent character design, soft rim lighting
```

## Personalidad
- Curioso, asombrado, nunca miedoso (aunque el tema dé "miedo", Chispa lo enfrenta con alegría).
- Hace la pregunta gancho al inicio de cada video.
- Cierra cada video con una frase de asombro tipo "¡La ciencia es asombrosa!" / "科学太神奇了！"

## Paleta de color fija
- Cuerpo: gradiente amarillo (#FFD54F) a naranja (#FF8A65)
- Ojos: blanco con iris azul brillante (#4FC3F7)
- Brillo/aura: amarillo pálido translúcido

## Uso recomendado
Incluir a Chispa como elemento recurrente en al menos 1 de los 4 prompts de cada video (normalmente el prompt de gancho o el de cierre), para que los espectadores lo reconozcan como la mascota del canal en ambos idiomas.
